# Beginner path — where to start

You do **not** need all 200+ concepts. Start here:

## 1. Essentials only (the most important 10)

Open **[Essentials](docs/index.html?mode=essentials)** or read [ESSENTIALS.md](ESSENTIALS.md).

Learn in this order (1–3 per day):

1. Grain  
2. Idempotency  
3. Shuffle  
4. Partition Pruning  
5. Predicate Pushdown  
6. Cardinality  
7. Lazy Evaluation  
8. Job → Stage → Task  
9. At Least Once  
10. Freshness  

**How to study each one (10–12 min):** definition → snippet → In prod → mark learned only if you can say it in one sentence.

## 2. When to use them in production

Open **[Prod](docs/index.html?mode=prod)** ([PROD.md](PROD.md)).

Match what you *see* (slow, duplicates, wrong KPI…) → do this → click concepts.

## 3. After the 10 — Must-know 30

[MUST_KNOW_30.md](MUST_KNOW_30.md) or app tab **Must 30**.

## 4. Practice (10 min/day)

**Stories** (pick 3 concepts) · Cards/Quiz decks = `essentials`

## What *not* to do

- Don’t browse all 200+ topics first  
- Don’t combine random tag + category filters  
- Don’t skip Grain / Idempotency / Shuffle  

Start now: [Essentials](docs/index.html?mode=essentials) → Grain → Idempotency → Shuffle today.
